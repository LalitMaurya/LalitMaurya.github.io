🔄 UPDATING DATA
═══════════════════════════════════════════════════════════════════════════════

EASY METHOD (Edit CSV directly):
  1. Open india_city_temperature.csv in Excel
  2. Add new rows with temperature data
  3. Save file
  4. Refresh browser
  Done! Data updates automatically.

SMART METHOD (Use Python script):
  1. Get Excel file with temperature data
  2. Run: python update_data.py your_file.xlsx
  3. Script converts to CSV automatically
  4. Refresh browser
  Done! Data updated and validated.
