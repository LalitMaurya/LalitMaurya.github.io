                 INDIA TEMPERATURE DASHBOARD - QUICK START

STEP 1: Download Files
- temperature_dashboard.html
- temperature_data.csv

Create a folder and put all 4 files together:
    
    my-dashboard/

    ├── city_metadata.csv
    └── README.md

- Simply double-click "temperature_dashboard.html"
- OR drag it into your browser
- Dashboard will load with latest available date selected

STEP 4: Interact with Dashboard
✓ Hover over map circles to see city details
✓ Change date using date picker (top left)
✓ Sort cards by clicking "Sort by" dropdown
✓ Explore temperature anomalies across Indian cities

================================================================================
                            DATA UPDATE INSTRUCTIONS
================================================================================

To add new temperature data:

1. Open temperature_data.csv in a spreadsheet or text editor
2. Add new rows with this format:
   
   date,city,tmax_normal,tmax,tmin_normal,tmin,tmax_anomaly,tmin_anomaly
   2026-07-28,New Delhi,38,39,28,29,1,1
   2026-07-28,Mumbai,34,35,26,27,1,1

3. Save the file
4. Refresh your browser to see updated data

NOTE: Date must be YYYY-MM-DD format (2026-07-28, not 28/07/2026)

To add new cities:

1. Add entry to city_metadata.csv:
   City_Name,Latitude,Longitude
   
2. Add corresponding temperature data rows to temperature_data.csv

                              CUSTOMIZATION TIPS
================================================================================

Change Dashboard Title:
→ Edit line with <h1> tag in HTML file

Change Color Scheme:
→ Modify colorScale definition in the script section

Adjust Map Zoom:
→ Change .scale(1200) value in projection settings (higher = more zoom)

Add Your Logo:
→ Add <img> tag in header section

================================================================================
                              TROUBLESHOOTING
================================================================================

Problem: Map doesn't show
→ Check internet connection
→ Check browser console (F12 → Console tab) for errors

Problem: No data appears
→ Verify CSV files are in same folder as HTML
→ Check city names match exactly between CSV files

Problem: Slow loading
→ Reduce data range in CSV
→ Close other browser tabs

Problem: Date picker empty
→ Ensure temperature_data.csv has data
→ Check date format (should be YYYY-MM-DD)
